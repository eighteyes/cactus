## Context

store.py is the only validator; a Swift write path must shell out to cactus answer --json or duplicate refusals/records. www.py already has SSE + feed API, so a WKWebView shell inherits every board fix for free. kitty-qa costs nothing and proves the hotkey habit before any Swift. Global hotkey: Carbon RegisterEventHotKey needs no Accessibility grant. Default if unanswered: kitty-qa first, swift-web second.

## Options

- kitty-qa — kitten quick-access-terminal running cactus --tui, hotkey via kitty, zero new code
- swift-web — Swift menu-bar app, global hotkey, floating NSPanel with WKWebView over www.py localhost board  (★◐)
- swift-native — SwiftUI panel reading SQLite directly, answers via cactus --json subprocess (mcp.py pattern)
